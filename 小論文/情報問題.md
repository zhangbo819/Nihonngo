# 情報問題

## 过去问-java

> 1　クラスの継承についてどういうものなのか　２００字
> ２　public/private/（デフォルト）/protected について、それぞれ説明せよ
> 3 setter/getterの役割について２００字程度で説明せよ
> ４ クラスメソッドとインスタンスメソッドはどういうものなのか　２００字程度
> ５ 抽象的クラスや抽象メソッドについてどういうものなのか　２００

1．クラスの継承について

```
クラスの継承とは、既存のクラスの属性やメソッドを、新しいクラスが引き継いで利用する仕組みである。継承元のクラスを親クラス、継承するクラスを子クラスという。子クラスでは、親クラスの機能をそのまま利用できるだけでなく、必要に応じて新しい属性やメソッドを追加したり、メソッドをオーバーライドしたりできる。これにより、共通する処理をまとめ、コードの再利用性を高めることができる。

```

2．public / private / デフォルト / protected

```
public、private、protected、デフォルトは、クラスやメンバへのアクセス範囲を指定する修飾子である。publicは、どのクラスからでもアクセスできる。privateは、同じクラスの内部からのみアクセスできる。protectedは、同じパッケージのクラスと、異なるパッケージであってもそのクラスを継承した子クラスからアクセスできる。デフォルトは修飾子を指定しない場合であり、同じパッケージ内からアクセスできる。

```

3．setter / getter の役割

```
setterとgetterは、クラスのフィールドを外部から安全に操作するためのメソッドである。getterはフィールドの値を取得するために使用し、setterはフィールドに値を設定するために使用する。通常、フィールドをprivateにして直接アクセスできないようにし、getterやsetterを通してアクセスする。この方法により、フィールドへのアクセスを制御でき、setterの中で値の妥当性を検証することもできる。そのため、カプセル化を実現する上で重要な役割を持つ。

```

4．クラスメソッドとインスタンスメソッド

```
クラスメソッドとは、クラスに属するメソッドであり、インスタンスを生成しなくても呼び出すことができる。Javaでは、staticを付けて定義する。一方、インスタンスメソッドは、クラスから生成されたインスタンスに属するメソッドであり、基本的にインスタンスを生成してから呼び出す。インスタンスメソッドは、そのインスタンスが持つフィールドの値を利用して処理を行うことができる。このように、両者はメソッドが属する対象と利用方法が異なる。

```

5．抽象クラス・抽象メソッド

```
抽象クラスとは、共通する属性やメソッドを定義し、他のクラスに継承されることを目的としたクラスである。抽象クラス自身はインスタンス化できない。抽象メソッドとは、メソッドの名前や引数などを定義するが、具体的な処理を持たないメソッドであり、abstractを付けて宣言する。抽象クラスを継承した子クラスは、抽象メソッドを実装する必要がある。これにより、共通するインターフェースを定めながら、具体的な処理を子クラスごとに定義できる。

```

## 过去问-http/ip

> １TCP/IPはインターネットの標準プロトコルとして最も普及しているプロトコル群である。TCP/IPのアプリケーション層プロトコルであるHTTPはステートレスなプロトコルである。HTTPがステートレスであることで生じる欠点とその欠点の解決策について、具体的な例を用いて１５０字
> 2 情報セキュリティマネジメントシステム（ISMS）で定義されている情報セキュリティの３要素（CIA）の名称を三つとも答えなさい。また、情報瀬リュリティの３要素の中から一つ取り上げ、その要素を確保するためのセキュリティ対策について１５０字

1. HTTP 是无状态协议的缺点与解决方案

```
HTTPはステートレスなプロトコルであり、サーバーは基本的に以前の通信内容を保持しない。そのため、例えばネットショッピングでログインした後、別のページに移動すると、ユーザーがログイン済みであることを判断できない場合がある。この問題を解決するために、Cookieやセッションを利用する。サーバーがセッション情報を保存し、Cookieなどを用いて利用者を識別することで、複数の通信を同じ利用者のものとして扱うことができる。

```

2. ISMS 的 CIA 三要素 + 一个安全措施

```
情報セキュリティの3要素は、機密性（Confidentiality）、完全性（Integrity）、可用性（Availability）である。例えば、機密性を確保するためには、利用者ごとにIDとパスワードを設定し、アクセス権限を適切に管理することが重要である。例えば、社員全員が顧客情報を閲覧できる状態にせず、業務上必要な社員だけにアクセスを許可する。これにより、許可されていない利用者による情報の閲覧や漏えいを防止できる。
```
