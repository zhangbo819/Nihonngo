有多少表达能够在没有答案提示时主动想起来，并在新题目中使用。

核心原则：训练量 ≠ 能力增长；熟悉感 ≠ 主动调用。第二周优先追求主动调用和迁移。

### 积木

① 単にAだけではなく、Bにもなります
② ～を通して、～
③ ～に役立つ可能性があります
④ ～ため、～
⑤ ～場合でも、～
⑥ ～ことが求められます
⑦ ～必要があります
⑧ ～につながります

1. 「ため・から・ので」核心区别

```
アルバイトで疲れたから、今日は勉強しない。
→ 我累了，所以今天不学习。（个人判断）

アルバイトで疲れたので、今日は勉強しません。
→ 因为累了，所以今天不学习。（比较柔和）

アルバイトで疲れたため、学習時間が減少しました。
→ 由于打工造成疲劳，学习时间减少了。（书面、客观）
```

2. 为什么「～につながる」觉得很好，却想不到怎么用？

当你脑子里出现“这件事进一步会……”

```
- 将来の仕事につながる
- 誤った判断を減らすことにつながる
- 学習効率の低下につながる
- 視野を広げることにつながる
- 同じ失敗を防ぐことにつながる
```

> 「～につながる」不是单纯表示“因果很弱”，而是把 A → B 表达成一种“发展方向/结果链条”，通常不把 B 说成 A 的必然结果。
> 「につながる」本身并不等于“可能”。

`努力は成功につながります。`

这里说话者完全可以认为这个关系很确定。

所以：

につながる = 因果链/发展方向

可能性があります = 不确定性

两者可以叠加：

AはBにつながる可能性があります。

“我提示存在这样一条可能的因果路径，但不宣称一定发生。”

## Day 5

> 2023年、アメリカでGMクルーズが運行していた自動運転タクシーに関する重大な事故が起きました。ある自動車が事故を起こし、被害者が道路上に倒れていたところ、この自動運転タクシーは被害者を約六メートル引きずってしまったのです。本来ならすぐに停車すべき状況でしたが、AIは「まず路肩に寄せてから止まる」という判断をしました。これは人間の運転者なら通常行わない対応であり、結果として被害を大きくしてしまいました。この事故をきっかけに、GMクルーズは自動運転タクシー事業から撤退しました。
> 自動運転技術にはまだ課題が多くあります。特に重要なのは次の四つです。
>
> 自動運転AIの判断力を高めること
> サイバー攻撃へのセキュリティ強化

> 法律の整備

```

```

④ 法律の整備

```
現在、自動運転技術の発展に対して、法律やルールの整備が十分ではないという問題があります。その背景には、自動運転車が事故を起こした場合、運転者だけでなく、メーカーや運行会社など、複数の関係者が存在することがあります。例えば、事故の原因がAIの判断にある場合、誰が責任を負うべきかを明確にする必要があります。そのため、自動運転車が満たすべき最低限の安全基準を法律で定めることが重要です。さらに、事故の原因を調査できるように、走行中の車両データを適切に保存する仕組みも必要です。事故が発生した場合には、保存されたデータを分析し、責任の所在を明らかにするべきです。したがって、安全基準だけではなく、事故後の調査や責任についても法律で明確にすることが重要だと考えます。
```
